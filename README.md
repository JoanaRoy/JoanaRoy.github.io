# Personal portfolio

A responsive, dependency-free portfolio. Open `index.html` in your browser to preview it. No installation or build step is required.

## Personalize

- Replace the sample name **Alex Morgan**, initials **am**, page title, description, biography, and skills in `index.html`.
- Replace both `hello@example.com` email links, including their `mailto:` addresses, with your real email.
- Edit the four sample project cards in `index.html` and their matching concept case studies in `portfolio.js`.
- Adjust the colors at the top of `styles.css`.

The project illustrations are made with HTML and CSS. Google Fonts is optional; system fonts are used when offline. All four projects are fictional concepts and should be replaced with your own work before sharing the portfolio as your professional website.

## Features

Responsive layouts, category filters, keyboard-accessible project dialogs, mobile navigation, email contact links, active section navigation, reduced-motion support, and a skip-to-content link.

## Hosting

Upload `index.html`, `styles.css`, and `portfolio.js` to any static website host. No server, API keys, or environment variables are needed.
